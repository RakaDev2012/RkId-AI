# RkId-AI
RkId AI adalah ai yang sangat ringan yang di rancang untuk handphone spek rendah 

# Spek
Minimal Ram 2GB, penyimpanan bebas 1GB+
Rekomendasi Ram 4Gb, penyimpanan bebas 1GB+

# Yang di butuhkan
Penjalan AI yang mendukung file AI berformat gguf

# Fitur AI ini
1 Mengobrol
2 Di ajak mengerjakan PR
3 Masih dalam tahap pengembangan

# Detail AI ini
1 Ukuran 500MB+
2 Ram yang di gunakan 300MB+
3 Bisa di jalankan di aplikasi apa saja dengan catatan mendukung format gguf
